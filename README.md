# Dr. Richa Singh — academic website

Source for the personal academic website of Dr. Richa Singh, Professor of
Biotechnology. Built with [Quarto](https://quarto.org) and published via GitHub Pages.

- `index.qmd` / `research.qmd` / `teaching.qmd` — the three pages
- `papers/` — one page + one PDF per publication
- `teaching/` — course-note PDFs · `tools/` — interactive HTML tools
- `_templates/paper-template.qmd` — starting point for a new paper page
- `_templates/publication-block.md` — copy-paste block for adding a paper to the list
- `images/headshot.jpg` — her portrait, square, used on the Profile page
- `cv/richa-singh-cv.pdf` — **scrubbed** CV. The mobile number, personal Gmail and
  both named referees have been removed. The unedited original lives in
  `private/source-assets/` and must never be copied here as-is. If the CV is
  refreshed, scrub it again before it goes into `site/`.

Rendered output (`_site/`) is generated by Quarto and is not committed.

## Design

The look is **"Ledger"** — direction B of `planning/design-directions-v1.html`,
chosen 27 Aug 2026. Sans-serif, one column about 70 characters wide, publications
as hairline-ruled rows with the year and version badge in a fixed left column.

All of it lives in **`styles.scss`**, which has two halves:

- `scss:defaults` — the variables. Colours and typefaces are changed here.
- `scss:rules` — the layout. Leave it alone unless the design itself is changing.

Two constraints the design depends on:

1. **The accent colour must not be green or amber.** Those two belong to the
   version badges (green = Open Access, amber = Accepted manuscript); an accent
   in either colour makes the badges stop meaning anything.
2. **Every paper entry keeps the same five elements in the same order** (v2 §3.4).
   The `::: pub` wrapper is what puts the year and badge in the left column —
   don't edit those lines.

`styles.css` is the old placeholder stylesheet. It is no longer loaded and can be deleted.

- `_quarto.yml` → `site-url: "https://drrichasingh.in"`. This is what makes every
